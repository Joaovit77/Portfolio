Site Cristo

Este projeto foi desenvolvido como um site informativo sobre a vida e ensinamentos de Jesus Cristo. O objetivo é oferecer uma navegação clara, conteúdo organizado e imagens impactantes, facilitando o acesso às informações para qualquer visitante.

O site conta com seções de estudos, histórias e testemunhos de fiéis, além de um design responsivo que se adapta a dispositivos móveis e desktops, garantindo uma experiência completa ao usuário.

3A Interiores

Este projeto é um site de portfólio de design de interiores, criado para exibir imagens de trabalhos, ideias de decoração e projetos conceituais. O layout destaca as imagens de forma organizada e visualmente atraente.

O design é responsivo e moderno, permitindo que os visitantes naveguem confortavelmente em qualquer dispositivo, transmitindo profissionalismo e atenção aos detalhes do conteúdo visual.

Dog do Ciri

Este site apresenta um cardápio digital para delivery, mostrando os produtos de forma clara e organizada. O layout foi desenvolvido para destacar imagens dos itens e informações relevantes, facilitando a visualização pelo usuário.

O design é responsivo e prático, permitindo que os visitantes acessem o conteúdo de forma intuitiva em qualquer dispositivo, oferecendo uma experiência simples e funcional

Tela de Login

Este projeto apresenta uma tela de login funcional e moderna. O objetivo é fornecer uma interface limpa e intuitiva para que o usuário possa acessar um sistema de forma rápida e segura.

O layout é totalmente responsivo e pode ser facilmente integrado a sistemas web maiores, servindo como base para aplicações futuras.
